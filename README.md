# Book Generator AI Agent
An AI agent that will generate a book given an outline

# Features
- User will supply an outline file as input. The file will be in FreeMind (.mm) format.
- User will supply a destination folder for book content. Book content will be in Leanpub markdown format described at https://leanpub.com/read/lfm.
- User will supply any API keys needed for LLM usage.

# Outline Format
- Second level entries in the outline are chapter titles in the book
- The order of the second level entries indicate the order of the chapters in the book
- Third level entries in the outline are section headers in the book
- Forth level entries are points that will be used to generate book text

# Book content format
- Each chapter of the book will be placed in a markdown file in folder manuscript. There will be one markdown file for each chapter provided in the outline.
- place chapter markdown file names in text file Book.txt in folder manuscript. Each line will contain one markdown file name. Put the file names in the chapter order provided in the outline. Only include the base name - not a fully-qualified file name.

# Chapter file format
- Place a heading at the start of each chapter with the name of the chapter from the outline 
- Each section header will be placed in the chapter at the H2 level
- section text generated by OpenAI will be placed in the sections indicated in the outline
